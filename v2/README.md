# Maximus Reach V2 (fresh start)

Separate from live V1 at the repo root. Nothing here goes live until you say so.

## Turn the preview on

```
cd v2
npm install
npm run dev
```

Open the localhost link (usually port 5174). Press Ctrl+C in the terminal when done.
