## StretchText v3 (per-letter)
- `components/ui/StretchText.tsx` splits the word into letters. Each letter gets its own `wdth` from a curve.
- Curves: ramp (narrow → wide), tail (last letters reach), peak, valley, flat, custom (`"100,112,128,140,151"`).
- Letters animate from narrow to their width on scroll-in (GSAP, staggered). Hover breathes +6 wdth on desktop.
- Roboto Flex default (wdth 25–151, opsz). Mona Sans option (75–125). Never scaleX.

## How we build (web dev)
- `BuildSiteCanvas.tsx` = the stage. Window starts as a 58% square with almost no chrome, grows per step (82/80%, 94/70%, 100/64%).
- Steps: 0 direction (crop marks, dot → rule) · 1 structure (nav band, espresso hero slab w/ REACH mark, CTA pill) · 2 trust (serif text band, avatars + 4.9, photo pane) · 3 finish (photo fill on slab, light sweep, two cards, Live badge, cursor glides in and presses the pill).
- Clip-path + transform reveals only. Reduced motion = instant states.
- `WebDevStickyProcess.tsx`: desktop pins stage left, steps scroll right. Mobile = one sticky 100svh stage, window on top, text under it, scroll snaps to steps via `window.__lenis.scrollTo`.
