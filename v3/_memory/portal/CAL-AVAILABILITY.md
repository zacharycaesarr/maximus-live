# Cal.com hours (you do this in Cal, not in code)

You work nights. Clients should not book 7am.

## Steps
1. Open [cal.com](https://cal.com) → sign in.
2. Open your event **booking** (`zachary-maximus-ambrcs/booking`).
3. Find **Availability** / schedule (sometimes under Event setup).
4. Set days/hours to when you actually take calls (example: 8pm–2am, or whatever is real).
5. Save.

The portal embed picks that up automatically. No code change.

Optional: add buffer time between meetings so you are not booked back-to-back.
